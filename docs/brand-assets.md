# 品牌素材使用说明

本仓库的原创代码与文档采用 [MIT 许可证](../LICENSE)。下列品牌素材单独适用本说明，其余权利由各自权利人保留。

## 素材范围

| 素材 | 位置 |
| --- | --- |
| 图灵镜及旗下产品的名称与标识 | 页面文案、图标和图片中的品牌名称与标识。 |
| 网站图标 | `public/favicon.svg`、`public/favicon.png`、`public/favicon.ico`。 |
| 首页 Logo 图形 | `src/render.mjs` 中 `heroLogo` 使用的 SVG 图形数据。模板与动画代码采用 MIT 许可证。 |
| RVC Fabric 官方截图 | `public/assets/products/rvc-fabric/` 中的图片。 |
| 官方 QQ 群二维码 | `public/assets/qq_group.jpg`。 |

`dist/` 中的对应副本适用相同说明。

## 使用方式

介绍、评测或编写图灵镜产品教程时，可以使用相应的品牌名称、Logo 和官方截图，并注明产品名称及[官网来源](https://www.turingmirror.com/)。Logo 保持原有比例与图形；截图可以缩放、裁剪或添加说明，编辑后的图片应准确呈现产品界面。

官方 QQ 群二维码可以用于引导用户加入图灵镜社区。基于本仓库发布其他网站时，请使用自己的站名、Logo 和社区联系方式。

品牌名称与标识用于识别图灵镜及其产品。将这些素材用于其他产品的品牌标识，或用于表示图灵镜合作、授权或推荐关系，须事先取得图灵镜同意。其他用途请通过[官网](https://www.turingmirror.com/)的商务合作入口联系。

截图中出现的第三方名称、标识和内容由各自权利人享有权利。
